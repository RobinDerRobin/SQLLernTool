# Recherche und Agenten-Berichte

Hier liegt jede Recherche und jeder Bericht der Design-Agenten (Game-Designer, Kritiker,
Prototyping-Experte) im Wortlaut. **Neue Recherche kommt in diesen Ordner**, Dateiname
`JJJJ-MM-TT-<thema>-<nr>-<rolle>.md`. Berichte sind Material, keine Entscheidungen. Verbindlich ist,
was Robin entschieden hat; das steht in [`../PROTOTYPEN.md`](../PROTOTYPEN.md) (Entscheidungsprotokoll).

Diese Datei lässt sich nicht direkt öffnen

Du hast index.html per Doppelklick geöffnet. Das kann nicht funktionieren: diese Datei lädt /src/main.ts, das erst von Vite übersetzt werden muss.

Zum Entwickeln im Projektordner ausführen:

npm run dev

… und dann http://localhost:5173 öffnen.

Zum Benutzen stattdessen die gebaute Einzeldatei nehmen:

npm run build

Das erzeugt dist/index.html — eine einzelne, in sich geschlossene Datei. Deren Inhalt fügst du in einen claude.ai-Chat ein; nur dort funktioniert auch der Claude-Chat im Tool.
